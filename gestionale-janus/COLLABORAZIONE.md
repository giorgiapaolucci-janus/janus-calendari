# Regole per chi lavora sul codice

- Collaboratrici con pari autonomia.
- Operare sul ramo `preparazione-janus`; non modificare `main`.
- Non modificare i file dei calendari nella radice del repository.
- Non pubblicare token, chiavi, archivio, assenze o backup.
- Leggere lo stato remoto prima di lavorare e prima del push; non forzare il push.
- Eseguire i test appropriati alle modifiche.
- Le fonti iniziali sono `app/data.js`, `importazione/` e i JSON base in `app/studenti/`; `archivio/` è locale.
- Non riattivare o introdurre una Chat interna senza una richiesta esplicita.
- Non configurare aggiornamenti ai servizi di produzione per i soli test.
